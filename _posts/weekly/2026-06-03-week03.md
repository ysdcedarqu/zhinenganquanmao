## 项目概述

区别于安全员用的多功能智能安全帽，工人用安全帽聚焦于 **低成本、长续航、轻量化** 的定位显示需求。核心功能：实时显示当前位置信息，辅助工人判断所处区域是否合规。

## 产品定义

| 维度 | 规格 |
|:---|:---|
| **目标用户** | 工地一线工人 |
| **核心功能** | 实时定位显示（GNSS + 室内定位） |
| **显示方式** | 墨水屏（低功耗、强光可读） |
| **安装位置** | 安全帽内侧（贴合帽体内壁） |
| **供电方式** | 纽扣电池（CR2032 或 CR2450） |
| **续航目标** | ≥ 6 个月（纽扣电池不可充电） |
| **成本目标** | 单帽 BOM ≤ ¥30 |

## 为什么选择 ESP32？

| 对比维度 | ESP32 | ESP32-S31 | 说明 |
|:---|:---|:---|:---|
| **价格** | ¥8–12 | ¥20–40（预估） | ESP32 成本更低 |
| **Wi-Fi** | Wi-Fi 4 | Wi-Fi 6 | 工人帽无需高速 Wi-Fi |
| **蓝牙** | BT 4.2 + BLE | BT 5.4 | BLE 信标定位够用 |
| **功耗** | Deep-sleep ~5μA | Deep-sleep ~7μA | ESP32 略优 |
| **生态成熟度** | 极成熟，资料丰富 | 新品，资料少 | ESP32 开发更快 |

> **结论**：工人帽追求极致低成本和长续航，ESP32 已经够用且更便宜、更成熟。

### 关键器件初选

| 器件 | 候选型号 | 说明 |
|:---|:---|:---|
| **MCU** | ESP32-C3 / ESP32 | C3 更低功耗，RISC-V 单核即可 |
| **GNSS** | ATGM336H / L76K | 低功耗 GNSS 模组，UART 通信 |
| **室内定位** | BLE 信标（ESP32 自带） | 利用 ESP32 的 BLE 扫描信标 RSSI |
| **墨水屏** | 2.13 寸 / 2.9 寸（SSD1680 驱动） | SPI 通信，静态显示零功耗 |
| **电池** | CR2450（3V / 600mAh） | 纽扣电池，低成本可更换 |
| **天线** | 陶瓷 GPS 天线 + PCB 蓝牙天线 | 内置于 PCB |

### 功耗估算

| 工作模式 | 电流 | 持续时间/频率 | 日均消耗 |
|:---|:---|:---|:---|
| **Deep-sleep（待机）** | ~5μA | 持续 | ~0.12mAh/天 |
| **GNSS 定位** | ~25mA | 每次 30s，每 5 分钟一次 | ~60mAh/天 |
| **BLE 扫描** | ~30mA | 每次 1s，每 10 秒一次 | ~72mAh/天 |
| **墨水屏刷新** | ~8mA | 每次 2s，每分钟一次 | ~6.4mAh/天 |
| **日均总消耗** | — | — | **≈ 139mAh/天** |

> ⚠️ 若 BLE 持续扫描则 CR2450（600mAh）仅能撑约 4 天。需要优化唤醒策略：仅在 GNSS 信号弱时启动 BLE 室内定位。

### 优化后的功耗策略

| 策略 | 措施 | 预期日均功耗 |
|:---|:---|:---|
| **室外优先** | GNSS 有信号时不启动 BLE | ~60mAh/天 |
| **BLE 按需唤醒** | 每 30 秒扫一次，每次 0.5s | ~12mAh/天 |
| **墨水屏仅在变化时刷新** | 位置不变不刷新 | ~1mAh/天 |
| **GNSS 降频** | 位置不变时延长定位间隔 | ~40mAh/天 |
| **优化后日均** | — | **≈ 53mAh/天** |

> ✅ CR2450（600mAh）优化后可撑 **约 11 天**；若改用 2×CR2450 并联可撑 **约 22 天**。

## 墨水屏显示内容

```
┌──────────────────┐
│  当前区域：B3 区   │
│  安全状态：✅ 合规  │
│  ───────────────  │
│  距危险区：12m     │
│  最近出口：← 东 30m │
│  信号：GNSS 🛰️ 4颗 │
└──────────────────┘
```

- 强光下清晰可读（墨水屏天然优势）
- 只刷新变化内容，节省电量
- 可加 LED 背光（夜间使用时短亮）

## 与安全员帽的定位差异

| 维度 | 安全员用安全帽 | 工人用安全帽 |
|:---|:---|:---|
| **主控** | ESP32-S31 | ESP32-C3 / ESP32 |
| **定位精度要求** | 高（需精确到区域） | 中（区域级别即可） |
| **显示需求** | 无（数据上报云端） | 墨水屏本地显示 |
| **供电** | 锂电池 2000–3000mAh | 纽扣电池 |
| **续航目标** | 8–12 小时 | 数天至数周 |
| **成本** | ¥40–65 | ≤ ¥30 |
| **通信** | 4G + Wi-Fi 6 | BLE / Wi-Fi（可选） |
