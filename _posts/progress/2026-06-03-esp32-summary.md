## 一、墨水屏驱动 — 核心成果

### 已验证的硬件配置

| 信号 | GPIO | 说明 |
|:---|:---|:---|
| SCK | 13 | SPI 时钟 |
| MOSI | 14 | SPI 数据输出 |
| CS | 15 | 片选 |
| DC | 27 | 数据/命令选择 |
| RST | 26 | 复位 |
| BUSY | 25 | 忙信号检测 |

> 以上配置来源于 `epaper_clock` 项目的 README，已在多个项目中反复验证，稳定可靠。

### 关键驱动模式

**1. 全刷（Full Refresh）**
```
EPD_5in83_V2_Init();
EPD_5in83_V2_Display(imageBuffer);
EPD_5in83_V2_Sleep();
```
- 适用于首次上电、内容大幅变更
- 功耗较高，有闪烁（墨水屏物理特性）

**2. 局部刷新（Partial Refresh）**
```
EPD_5in83_V2_Init();
EPD_5in83_V2_Display_Partial(imageBuffer, x, y, w, h);
EPD_5in83_V2_Sleep();
```
- 适用于时钟秒数更新、位置文本变化
- 功耗低，无闪烁
- `epaper_clock_qt` 中已实现秒级局刷

**3. 休眠模式**
```
EPD_5in83_V2_Sleep();
```
- 进入低功耗状态，适合电池供电场景
- 配合 ESP32 Deep-sleep 可大幅降低待机功耗

### 图像资源生成

使用 `convert_image.py` 将 PNG 转为墨水屏专用 C 数组：
```
python3 convert_image.py input.png
```
生成的文件可直接嵌入固件，作为墨水屏显示素材（图标、LOGO、背景等）。

## 二、WiFi + 网络通信

### NTP 时间同步

```cpp
configTime(8 * 3600, 0, "ntp.aliyun.com", "ntp.ntsc.ac.cn");
```
- 使用阿里云和国内 NTP 服务器，工地网络环境友好
- 可用于安全帽时间戳记录

### HTTP 数据获取

```cpp
HTTPClient http;
http.begin("https://api.example.com/data");
int code = http.GET();
```
- 已在 `epaper_clock` 中验证（天气 API 调用）
- 可改造为云端定位数据上报

### SSH 日志上传（`ssh_log_uploader`）

- 使用 `LibSSH-ESP32` 库
- FreeRTOS 独立任务处理 SSH 连接
- SPIFFS 存储本地日志
- 可用于安全帽异常事件日志上传

## 三、micro-ROS 通信验证

`microros_publisher` 已验证：
- ESP32 通过 WiFi UDP 连接 micro-ROS Agent
- 发布 `/esp32_counter` 话题（1Hz）
- 订阅 `/esp32_led` 控制板载 LED

```cpp
rcl_publisher_init(&publisher, &node, 
    ROSIDL_GET_MSG_TYPE_SUPPORT(std_msgs, msg, Int32), 
    "/esp32_counter", &rmw_qos_profile_default);
```

> 对未来意义：若安全帽需接入 ROS2 机器人/工地管理系统，此方案可直接复用。

## 四、低功耗实践总结

### 已验证的省电策略

| 策略 | 实现方式 | 效果 |
|:---|:---|:---|
| 墨水屏休眠 | `EPD_Sleep()` 后墨水屏零功耗保持画面 | 关键 |
| ESP32 Deep-sleep | `esp_deep_sleep_start()` | 待机 ~5μA |
| WiFi 按需连接 | 先连 WiFi → 获取数据 → 断开 → 休眠 | 大幅省电 |
| 局刷代替全刷 | `Display_Partial()` | 减少刷新功耗 |

### 建议的工人帽工作流程

```
启动 → WiFi连接 → NTP同步 → GNSS定位
  → 墨水屏全刷显示 → 墨水屏休眠 → ESP32 Deep-sleep
  → 定时唤醒 → 局刷更新位置 → 继续休眠
```
