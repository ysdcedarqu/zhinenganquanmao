## 核心规格

| 项目 | 参数 |
|:---|:---|
| **SoC** | 全志 A733 |
| **CPU** | 2× Arm Cortex-A76 + 6× Arm Cortex-A55，最高 2.0 GHz（八核异构） |
| **GPU** | Imagination PowerVR BXM-4-64 MC1，支持 OpenGL ES 3.2 / Vulkan 1.3 / OpenCL 3.0 |
| **NPU** | 最高 3 TOPS @INT8，支持 INT8 / INT16 / FP16 / BF16 混合精度 |
| **协处理器** | 玄铁 E902 RISC-V 实时核心，最高 200 MHz |
| **内存** | 板载 LPDDR5，最高 16 GB |
| **存储** | 板载 eMMC：8/16/32 GB 可选（默认空贴）；板载 UFS：32/64/128 GB 可选（默认空贴）；TF 卡槽：最高 128 GB |

## 无线连接

| 项目 | 参数 |
|:---|:---|
| **Wi-Fi** | Wi-Fi 6（802.11ax） |
| **蓝牙** | 蓝牙 5.4（BLE），支持外接天线 |

## 显示与摄像头

| 项目 | 参数 |
|:---|:---|
| **显示输出** | 1× Mini HDMI 2.0（最高 4K@60fps）；1× 4-lane MIPI-DSI；1× Type-C（DP Alt 模式，最高 4K@60fps）；支持双屏异显 |
| **摄像头** | 2× 4-lane MIPI CSI |

## 扩展接口

| 项目 | 参数 |
|:---|:---|
| **GPIO** | 40 PIN 功能扩展接口，支持 GPIO / UART / I2C / SPI / PWM |
| **高速扩展** | 1× PCIe 3.0 1-Lane FPC 插座 |
| **风扇** | 2 PIN 风扇接口 |

## 物理特性

| 项目 | 参数 |
|:---|:---|
| **电源** | Type-C 5V / 3A DCIN |
| **尺寸** | 65mm × 32mm × 1.2mm |
| **典型功耗** | 约 5–15W（视负载而定） |

## 软件生态

- **操作系统**：Android、Debian、Ubuntu、OpenHarmony
- **AI 框架**：ONNX、TensorFlow、PyTorch、Caffe（提供从模型导入到部署的全流程工具链）
- **典型场景**：嵌入式 AI、边缘计算网关、智能显示终端、轻量级服务器、教育创客
