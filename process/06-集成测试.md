## 目标

完成硬件与软件的集成测试、功能测试、可靠性测试，确保系统在真实工况下稳定运行。

## 主要工作

- [ ] 功能逐项测试（佩戴检测、跌倒检测、定位、SOS、语音、视频等）
- [ ] 端到端流程测试（安全帽 → 4G → 云端 → 管理端）
- [ ] 续航测试（典型工况 8h 验证）
- [ ] 环境可靠性测试（高温、低温、振动、防水）
- [ ] 工地现场实测
- [ ] Bug 修复和迭代优化

## 测试标准

| 测试项 | 通过标准 |
|--------|----------|
| 佩戴检测 | 准确率 ≥ 99% |
| 跌倒检测 | 检出率 ≥ 95%，误报率 ≤ 5% |
| 续航 | ≥ 8h（典型工况） |
| SOS 响应 | 端到端 ≤ 5s |
| 4G 通信 | 连接成功率 ≥ 99% |

## 交付物

- 测试用例和测试报告
- Bug 列表及修复记录
- 现场测试报告
