## 目标

基于需求分析结果，设计系统整体方案，包括硬件架构、软件架构、通信方案和安全帽内部模块布局。

## 主要工作

- [x] 主控芯片方案对比论证（OPi Zero 3W vs ESP32-S31）
- [x] 主控芯片最终确定：ESP32-S31-WROOM-3
- [x] 定位模块方案初步确定（GNSS + BLE 混合）
- [ ] 设计硬件系统架构（基于 Korvo-1 参考设计裁剪）
- [ ] 设计安全帽内部模块布局方案
- [ ] 确定数据传输协议（4G 上报格式、云端接口）
- [ ] 功耗分析与优化策略

## 关键决策点

1. **MCU 选型方向**：高性能 ARM Cortex-M vs 低功耗 RISC-V
2. **定位方案**：GNSS 单模 vs GNSS+BLE 混合
3. **音频方案**：Codec 芯片 vs 集成音频 MCU
4. **模块间通信**：I2C/SPI/UART 接口分配
